# AH股IPO评分系统

📊 基于历史IPO回测的条件Beta评分系统

## 在线访问

👉 [点击打开评分系统](https://mengchiwlab.github.io/Dave/)

## 使用方法

1. 输入A股6位代码，点击「获取数据」
2. 系统自动计算 Beta / Alpha / 45日涨幅 / 价格位置
3. 输入AH折价率、基石占比等参数
4. 点击「评分」查看结果

## 评分逻辑

- **条件Beta**：市场涨时高Beta加分，市场跌时高Beta减分
- **AH折价率**：折价越高评分越高
- **基石占比**：基石投资者占比越高越稳

## 数据来源

- A股K线：腾讯财经API
- 沪深300基准：腾讯财经API
- 市值数据：腾讯财经API

## 本地运行

直接打开 `ah_ipo_v59_web.html` 即可，纯前端无需后端。
